# Causette 2 development coverage

Causette 2 uses the public kChat feature guides as a behavioral reference. The design and hosting contract remain those of Causette. The development build targets the web app and the existing browser-based installation and update paths.

| Capability | Causette 2 development state |
| --- | --- |
| Personal messages, private and public groups, invitations and moderation | Inherited. See the [functional coverage](functional-coverage.md) for the tested group and account flows. Separate teams and workspaces, general-channel rules, channel descriptions and announcement-only posting remain open. |
| Conversation switching, favorites, sidebar organization and unread indicators | The switcher searches existing conversations by name or number and supports Ctrl+K or Command+K, arrow keys, Enter and Escape. The sidebar can group unread conversations at the top. The existing personal favorites and custom list remain available. Multiple categories, group favorites and mark-unread remain open. |
| Group or personal message threads | Select a message's thread action to view and send replies in a dedicated panel. Replies use stable pagination and safe text rendering. Members can follow a thread and open it from an in-app notification. Repeated submissions with the same client key acknowledge the existing reply. A central list of followed threads, reply editing and deletion, thread attachments and reactions, and indexing thread replies for search remain open. |
| Saved messages | Private account-level bookmarks, with a limit of 100. The list rechecks membership each time and excludes archived conversations. Its search uses the same filters as regular message search. A result can open a bounded historical view without advancing the current read position. |
| Search | Search the conversations joined by the account and filter by `from:`, `in:`, `before:`, `after:` and `on:`. Quote a name or phrase with spaces. Prefix text, `from:` or `in:` with `-` to exclude it. `after:` starts on the next calendar day in the account time zone. File-content indexing remains open. |
| Appearance and navigation preferences | Existing light, dark and blue-orange themes, plus a device-following theme. Accounts can choose message spacing, conversation width, where to open a conversation, whether attachment thumbnails load inline, and how unread conversations are displayed. Web page previews, quick-reaction history, last-activity visibility, automatic time zone changes and a complete shortcut directory remain open. |
| Notifications | All messages, personal mentions or silence per conversation, for both regular and bot messages. Followed threads create in-app notifications with deep links. Silencing a conversation suppresses these as well. Existing account-level sound, browser notification and Web Push settings remain available. Thread delivery through Web Push, notification keywords, presence-based routing and email summaries remain open. |
| Attachments, reactions, polls, calls and screen sharing | Inherited. Conversation-level file browsing, custom organization emoji and larger call scenarios remain open. |
| Composer and time-based actions | The current composer supports quotes, mentions, attachments and emojis. Rich formatting, audio messages, reusable drafts, scheduled sends and reminders remain open. Scheduled work must account for the availability of a hosting-panel trigger. |
| Service integrations | The Causette bot endpoint remains supported. Slash commands, generic webhooks, calendar and mail bridges, AI features and native clients remain open. Opening an existing kDrive link does not require access to a kDrive account by the Causette server. |

The 2.0.0-dev package uses database schema 1.0.8. The existing browser updater creates the reply and follow tables. It stops before advancing the schema marker if the required table structure is absent or incompatible. Permanently deleting a root message also deletes its replies and follows.
